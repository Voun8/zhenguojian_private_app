# 红果鉴 / 真果鉴

红果鉴和真果鉴是基于 Flutter 的多端短剧应用。浏览、搜索、选集、播放、下载与管理均在设备端完成，不依赖自建服务。当前源码版本为 **0.2.59+65**，属于开发快照。

## 两个版本

| 应用 | 站源范围 |
| --- | --- |
| 红果鉴 | 仅红果 |
| 真果鉴 | 红果及项目已接入的其他站源 |

两版在构建时确定站源范围，不能在应用内切换。Android 两版使用同一应用标识和数据目录；签名相同时可互相覆盖升级，不能并排安装。

## 主要功能

- 分类浏览、榜单与搜索，查看剧集资料并选择分集播放。
- 播放控制、错误重试、观看记录与追剧提醒。
- 分集下载、离线播放、本地文件管理与备份恢复。
- 多用户及站源权限管理；真果鉴可分别管理已接入站源。
- 手机、电脑和电视布局；Android TV 支持遥控焦点操作。

## 下载

安装包发布在 GitHub [Releases](https://github.com/Voun8/duanju_app/releases)。每个版本提供：

| 平台 | 文件 | 使用方式 |
| --- | --- | --- |
| Android | 对应设备架构的 `.apk` | 多数手机选择 `arm64-v8a`；旧 32 位设备选择 `armeabi-v7a`；x86_64 用于对应设备或模拟器 |
| Windows 10/11 x64 | `windows-x64.zip` | 完整解压后运行包内 `.exe`，保留 DLL 和 `data` 目录 |
| iOS | `ios-altstore.ipa` | AltStore 兼容 IPA，安装时使用自己的 Apple ID 重签名 |

Release 附有 `SHA256SUMS.txt`，用于校验下载文件。新版本在 Android、Windows 和 iOS 两版构建全部成功后自动发布为预发布版本。Android 覆盖升级要求新旧安装包使用相同签名。

## 当前状态

Android 手机与 Windows 是优先交付平台；Android TV 随 Android 包提供，iOS 后续单独适配。当前代码和自动构建产物尚未完成本版本的真实设备与站源播放集中验收。
